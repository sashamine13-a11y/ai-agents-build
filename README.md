# AI Agents

Multi-agent Android app for working with AI models via API.

## Supported Models (work in Russia without VPN)

| Provider | Model | Free Limit | Registration |
|----------|-------|------------|--------------|
| Gemini | gemini-1.5-flash | 60 req/min | aistudio.google.com |
| DeepSeek | deepseek-chat | ~$5 credits | platform.deepseek.com |
| Qwen | qwen-turbo | 1M tokens/month | dashscope.aliyun.com |
| Mistral | mistral-tiny | 1 req/sec | console.mistral.ai |

## Build via GitHub Actions

1. Fork this repository
2. Go to Actions → Build APK → Run workflow
3. Download APK from artifacts after ~5 minutes

## Setup

1. Open the app
2. Tap Settings (gear icon)
3. Enter at least one API key
4. Start chatting!
